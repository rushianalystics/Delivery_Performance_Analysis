# Delivery Performance and Logistics Analysis

## Project Overview
This project analyzes delivery performance using MySQL and Power BI. The main objective is to understand delivery delays, delivery time, delivery cost, and delivery partner performance.

## Tools Used
- MySQL
- Microsoft Power BI
- DAX

## Dataset
The dataset contains delivery-related information, including delivery partners, regions, vehicle types, delivery modes, delivery time, cost, and ratings.

## Key Analysis
- Total, delayed, and on-time deliveries
- Delay percentage by delivery partner
- Delayed deliveries by region
- Average delivery time for delayed and on-time deliveries
- Average delivery cost by delivery mode
- Delivery partner ratings

## Dashboard Features
- KPI cards
- Interactive charts
- Slicers for delivery partner, region, and delivery mode

## Project Files
- `delivery_performance_analysis.sql` — SQL analysis queries
- `delivery_performace_analysis.xlsx` — Dataset
